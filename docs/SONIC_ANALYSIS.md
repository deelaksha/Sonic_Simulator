## Simulation vs real-device suitability

- **Config commands** change device/packet behavior → primarily **simulation** targets (must drive the engine).
- **Show/verification commands** map cleanly to **both** simulation (rendered from state) and **real-device** mode (parse device output).
- **DB / redis-cli / env-setup** commands are environment plumbing → **real-device / setup only**, not simulated behavior.
